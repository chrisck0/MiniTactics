# 페이즈 상태

## 📝 1. 기능 개요

### 1.1. 기능 정의

- 아군 페이즈, 적군 페이즈를 전환했을 때 각 페이즈에 맞는 행동 시작

### 1.2. 구현 목표

- 각 페이즈를 상태로 만든 다음, 상태 패턴을 사용하여 페이즈 전환

- 아군 페이즈에서는 유저가 아군 유닛에게 직접 명령하거나 아군 유닛이 자동 행동

- 적군 페이즈에서는 적 유닛이 자동 행동

- 각 페이즈 시작에서 필요한 정보를 초기화

## 🛠️ 2. 작성 클래스 설계 및 구조 

### 🔗 2.1. 클래스 간 관계도

## 핵심 클래스 세부 역할

### `PhaseStateController.cs`

- **페이즈 상태 초기화 (`InitPhaseStates()`)**: 턴의 세이브 데이터를 가지고 유닛의 데이터를 설정

- **턴 세이브 데이터 저장 (`SaveTurnSaveData()`)**: 턴 되돌리기 기능 및 중단 지점부터 게임 시작을 위한 세이브 데이터 저장

- **아군/적군 페이즈 전환 (`StartPlayerPhase`, `StartEnemyPhase`)**: 아군/적군 페이즈를 전환시키고, 전환될 때 외부에게 전달

<br>

### `PlayerPhaseState.cs`

- **자동 행동 (`Behave()`)**: 플레이어가 직접 명령하는 것이 아니라 남은 행동 가능 유닛 중 하나를 선택하여 자동 행동하도록 명령

- **유닛 행동 끝났을 때 `UnitCommandStateController`를 초기화 (`UnitCommandEnd`)**: 플레이어가 직접 유닛을 조작하여 명령을 내린 다음, 다시 새 유닛을 선택하여 명령을 내릴 수 있도록 `UnitCommandStateController` 초기화

- **모든 적군이 행동한 다음 아군 페이즈로 전환 (`PlayerPhaseEnd`)**: 아군 페이즈가 끝났다고 `PhaseStateController`에게 전달

<br>

### `EnemyPhaseState.cs`

- **자동 행동 (`Behave()`)**: 적군 유닛 중 하나를 자동 행동하도록 명령

- **모든 적군이 행동한 다음 아군 페이즈로 전환 (`EnemyPhaseEnd`)**: 적군 페이즈가 끝났다고 `PhaseStateController`에게 전달

<br>

### 🔄 2.2. 페이즈 전환

## 단계별 세부 설명

### 1. 페이즈 정보 초기화 (`InitPhaseStates()`)

- 기존에 저장되었거나 새로 만든 턴 세이브 데이터를 가지고 페이즈 상태와 유닛의 데이터를 초기화

- `PlayerPhaseState`, `EnemyPhaseState`, `PhaseEndState` 객체를 생성

<br>

### 2. 아군 페이즈 시작 (`StartPlayerPhase()`)

- 턴의 세이브 데이터 저장 (중단했을 때 세이브 데이터를 남기거나, 턴을 되돌릴 때 각 턴의 세이브 데이터가 필요)

- 턴 시작 전에 턴 제한을 넘겼는지 확인

- 아군 페이즈로 전환

<br>

### 3. 아군 페이즈 (`PlayerPhaseState`)

- 유저가 직접 아군 유닛을 조작하거나 아군 유닛에게 자동 행동 명령 가능

- 아군 유닛이 행동하면 나머지 행동 가능한 아군 유닛이 행동할 수 있도록 `UnitCommandStateController`의 상태를 처음으로 초기화

- 남은 행동 가능 유닛 중 하나를 선택하여 자동 행동 가능

- 모든 아군이 행동한 다음 적군 페이즈로 전환

<br>

### 4. 적군 페이즈 (`EnemyPhaseState`)

- 행동 가능한 적군 유닛 중 하나를 선택하여 자동으로 행동

- 모든 적군이 행동한 다음 아군 페이즈로 전환
  
<br>
