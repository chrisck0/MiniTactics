# 유닛 명령 상태

## 📝 1. 기능 개요

### 1.1. 기능 정의

- 행동 가능한 유닛 중 하나에서 선택, 이동, 명령, 공격 타겟 선택, 행동 완료를 진행할 수 있어야 함

### 1.2. 구현 목표

- 상태 패턴을 사용하여 선택, 이동, 명령, 공격 타겟 선택, 행동 완료 상태로 각각 나누고, 전이 조건을 만족하면 상태 전환

---

## 🛠️ 2. 작성 클래스 설계 및 구조 

### 🔗 2.1. 클래스 간 관계도

## 핵심 클래스 세부 역할

### `UnitCommandStateController.cs`

- **플레이어 유닛, 무기 선택 (`SetSelectedPlayerUnit()`, `SetSelectedWeaponData()`)**: 명령당할 유닛과 공격할 무기를 선택하여 저장

- **UI 보여주기/가리기**: 유닛 명령 전반에서 공통적으로 보여줘야 하는 UI들을 보여주고 가리는 것을 관리

- **상태 변화 시 이벤트 발화 (`OnStateChanged`)**: 상태가 전환되면 `StateMachine`에게 이벤트 전달

- **상태 전환 (`SetState()`)**: 특정 상태로 전환

<br>

### `StateMachine.cs`

- **상태 전환 (`ChangeState()`)**: 현재 상태를 보관하여, 상태가 변화될 때 각 상태의 `Exit()`과 `Enter()`를 실행

- **현재 상태의 Update 실행 (`Update()`)**: 현재 상태의 `Update()`를 실행해서 현재 상태에서 매 프레임 실행되어야 하는 함수 실행

<br>

### `UnitSelectState.cs`

- **타일 커서 탐색 (`Update()`)**: 타일 커서가 위치한 타일에 raycast를 해서 해당 타일 위에 무엇이 있는지 확인

- **유닛 선택 (`Select()`)**: 타일 커서가 위치한 타일 위에 유닛이 존재할 때 선택하는 경우, 아군 유닛일 때는 유닛 이동 상태로 전환되고 적군 유닛일 때는 유닛의 위험 범위 표시

- **유닛의 이동, 공격 범위 표시 (`ShowDistanceRange()`)**: 유닛의 이동, 공격 범위를 보여주고, 적군의 경우 예상 공격 대상 표시

- **시스템 설정 보여주기(`ShowSystemCommand()`)**: 타일 커서가 빈 타일을 가리켰을 때 선택하는 경우, 시스템 설정 UI 표시

<br>

### `UnitMoveState.cs`

- **이동 범위, 공격 범위 표시 (`ShowDistanceRange()`)**: 유닛의 이동, 공격 범위를 표시

- **타일 선택**: 선택한 타일이 이동 가능한 타일이면 해당 위치로 이동하고 유닛 명령 상태로 전환, 이동 불가능 한 타일이면 유닛 선택 상태로 전환

- **유닛 이동 (`MoveToDestination()`, `MoveUnit()`)**: 목적지 타일까지의 최단 경로를 따라 유닛 이동

<br>

### `UnitCommandState.cs`

- **유닛 명령 UI 보여주기 (`Enter()`)**: 유닛 명령 상태에 진입하면, 유닛 명령 UI 창 활성화

- **공격 (`Attack()`)**: 유닛 명령 UI에서 공격을 선택했을 때, 공격 명령 UI를 활성화

- **대기 (`Wait()`)**: 유닛 명령 UI에서 대기를 선택했을 때, 명령 끝 상태로 전환

- **무기 선택 (`WeaponSelected()`)**: 무기가 선택되면 타겟 선택 상태로 전환

<br>

### `TargetSelectState.cs`

- **공격 대상 또는 방향 설정 (`Update()`)**: 공격 대상을 선택하는 경우 타일 대상이 선택 가능하다면 공격 대상을 선택, 방향을 선택하는 경우 해당 공격 범위 내 타겟이 존재한다면 공격 방향 선택 가능

- **무기 방향 설정 (`GetWeaponDirection()`)**: 현재 유닛이 위치한 곳과 타일 커서가 위치한 곳을 비교하여 4방향으로 무기 방향 설정

- **공격 (`Attack()`)**: 공격 타겟 대상에게 공격하고 반격 가능한 타겟 대상에게 반격 당하고 명령 끝 상태로 전환

<br>

### `CommandEndState.cs`

- **유닛 행동 완료 전달 (`OnUnitCommandEnd`)**: 명령 끝 상태에 진입하면 이벤트를 전달하여 선택한 유닛이 행동 완료했다는 것을 전달

<br>

### 🔄 2.2. 유닛 명령 상태 전환

## 단계별 세부 설명

### 1. 유닛 선택 (`UnitSelectState`)

- 타일 커서를 움직여서 타일을 선택
  - **아군 선택**: 행동하지 않은 유닛이라면 선택하고, 유닛 이동 상태로 전환
  - **적군 선택**: 위험 범위 표시
  - **유닛 없는 타일 선택**: 시스템 명령 UI 표시

- 타일 커서 위 유닛의 이동 및 공격 가능 범위 표시

<br>

### 2. 유닛 이동 (`UnitMoveState`)

- 선택한 유닛의 이동 및 공격 가능 범위 표시

- 이동 범위 내의 타일을 선택하면 해당 타일로 최단 경로를 따라 이동하고 유닛 명령 상태로 전환

- 이동 범위 외의 타일을 선택하거나 취소를 입력하면 유닛 선택 상태로 전환

<br>

### 3. 유닛 명령 (`UnitCommandState`)

- 공격 또는 대기 상태 명령 가능, 취소하면 유닛 선택 단계로 전환

- 공격 상태를 선택했다면 공격 명령 UI를 보여주어 무기 선택이 가능하고, 선택하면 타겟 선택 상태로 전환

- 대기 상태를 선택했다면 명령 끝 상태로 전환

<br>

### 4. 타겟 선택 (`TargetSelectState`)

- 타일 커서에 따라 원하는 타겟을 선택하거나 무기 방향 선택 가능

- 선택한 무기가 타겟을 선택해야 하는 무기인 경우, 목표 사거리 내의 범위 표시

- 선택한 무기가 공격 방향을 선택해야 하는 무기인 경우, 선택한 유닛과 타일 커서의 위치에 따라 공격 방향을 표시

- 선택한 범위가 공격 가능하면 타겟 좌표의 적 공격

<br>

### 5. 명령 끝 (`CommandEndState`)

- 상태에 들어오면 `OnUnitCommandEnd`를 발화하여 선택한 플레이어 유닛의 행동이 완료되었음을 전달

<br>
